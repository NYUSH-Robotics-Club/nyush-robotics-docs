# NYUSH Robotics Docs

Technical documentation for NYU Shanghai Robotics Club.

## Getting Started

1.  **Install dependencies**

    ```bash
    npm install
    ```

2.  **Run locally**

    ```bash
    npm run docs:dev
    ```

3.  **Build**

    ```bash
    npm run docs:build
    ```

4.  **Preview build**

    ```bash
    npm run docs:preview
    ```

## Directory Structure

- `docs/zh/`: Chinese documentation (Main)
- `docs/en/`: English documentation (Derived)
- `docs/public/`: Static assets (images, etc.)
