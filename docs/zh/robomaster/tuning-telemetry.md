# 调参与遥测

## PID 调参顺序

建议顺序：

1. 先内环（电流/速度），后外环（角度）
2. 先 `P` 再 `D`，最后 `I`
3. 前馈用于降低稳态误差与响应滞后

注意：

- 不要一上来三环全开
- 频率、滤波、限幅必须和 PID 一起设计

## Ozone 观测建议

关注三类时域指标：

- 上升时间
- 超调量
- 稳态误差

每次只改一个变量（参数或结构），否则无法定位因果。

## RTT Dashboard 在线遥测

`rtt-dashboard` 能实时观察：

- 电机目标值与反馈值
- 云台目标角与实际角
- 遥控器状态位
- CAN 在线位图
- 丢帧和 CRC 错误趋势

建议把遥测当成“联调主界面”，减少盲调。
