# 赛季与规则（RoboMaster）

## 当前赛季快照（截至 2026-02-16）

- `RMUC 2026`：官方公告显示报名于 `2026-01-10` 开启，总决赛计划在 `2026 年 8 月`。
- `RMUL 2026`：官方公告显示资格赛覆盖美洲、欧洲、日本、东南亚，总决赛在中国举办。

规则结论：

- 战术、机构、电控和视觉方案，都必须以当季规则与补充公告为准。
- 队内历史文档只能作为工程经验，不可替代当季规则判定。

## 规则阅读流程（建议）

1. 先通读比赛规则手册和制作规范。
2. 再读当季 FAQ / 判例 / 补充公告。
3. 最后把“我方方案对应的规则条款”写入设计文档。

建议固定输出三张表：

- `功能-条款映射表`
- `风险条款清单`（触发即可能判罚）
- `赛前复核清单`

## 队内版本管理建议

- 每周至少检查一次官方公告页。
- 每次训练前确认本地引用的是最新规则版本。
- 每个 PR 若涉及策略或机构，应附规则条款引用。
