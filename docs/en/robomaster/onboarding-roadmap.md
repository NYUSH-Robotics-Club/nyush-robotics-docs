# Onboarding Roadmap (8 Weeks)

## Week 1-2: Toolchain and Minimum Loop

- configure Git, VSCode, compiler toolchain
- build and flash successfully
- understand repository structure and main tasks

## Week 3-4: Communication and Feedback

- bring up CAN TX/RX
- understand motor feedback fields
- distinguish comm failures from control failures

## Week 5-6: Control and Kinematics

- tune single-motor speed loop baseline
- understand kinematics and output limits
- produce parameter logs and experiment notes

## Week 7-8: Integration and Engineering Discipline

- add telemetry and logs
- standardize troubleshooting sequence
- produce handoff-ready docs and rollback version

## Weekly Deliverables

- one runnable branch
- one change log page
- one reproducible experiment result
